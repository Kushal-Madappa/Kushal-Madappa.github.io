Projects

Best Paper, ICACECS 2025

Brain tumour classification from MRI

  • Python
  • TensorFlow
  • Keras
  • Flask
  • Two-stage pipeline on 7,023 MRI scans: VGG19-UNet segmentation isolates the tumour region, then EfficientNetB1 classifies glioma, meningioma, pituitary tumour or no tumour.
  • A baseline CNN reached 96% test accuracy; EfficientNetB1 with transfer learning came close to perfect. Investigating that gap exposed a likely patient-level leakage risk in the public train/test split, which grouped cross-validation by patient would address.
  • Served the model through a Flask app that accepts an MRI upload and returns a prediction.

Malware detection web app

  • Python
  • scikit-learn
  • pandas
  • Flask

Classifies Windows executables as malicious or benign from static file features, without running them. I cleaned malformed entries, encoded header fields and corrected class imbalance, then chose HistGradientBoosting after benchmarking it against simpler baselines. Evaluation focused on recall, since a missed malicious file costs more than a false alarm. A Flask front end returns a label and confidence for any uploaded .exe.

Gesture-based volume control

  • Python
  • OpenCV
  • MediaPipe

Controls system volume with hand gestures from an ordinary webcam. MediaPipe tracks finger landmarks frame by frame and maps the thumb-to-index distance to volume, with smoothing and thresholds to stop detection jitter from changing the level. The loop is tuned to stay responsive on consumer laptops.
